# 🎲 D20Age RPG — Foundry VTT

Bring your **D20Age RPG** adventures to Foundry VTT with themed character sheets, step-by-step character creation, and tools to prepare and run your sessions.

The system brings together features from the **Core Rulebook V2** in an interface inspired by old-school aesthetics, featuring pencil sketches, black-and-white artwork, and the distinctive **Ink and Hatching** style.

## ✨ Why Use It?

Create characters with guidance at every step, browse equipment and spells directly in Foundry, and prepare encounters with an organized bestiary. Bring your adventuring party together on a group sheet, distribute treasure among its members, and keep track of the supplies carried by pack animals.

## 🎯 Key Features

- 🎨 **Themed Sheets** — Character sheets in both the default and Ink and Hatching styles, plus a dedicated creature sheet.
- 🧭 **Character Creator** — Guided, step-by-step creation covering class choices, attributes, resources, and equipment.
- 📚 **Organized Compendiums** — Equipment, abilities, spells, creatures, tables, and macros for quick reference and session preparation.
- 🐉 **Bestiary** — Creatures organized by type, with entries ready to import and use in encounters.
- 🛡️ **GM Creature Panel** — Quick-reference tools to help Game Masters manage encounters.
- 👥 **Party Sheet** — Linked characters, a shared treasure stash, a journal, and a transfer history.
- 🫏 **Pack Animals** — A compendium of pack animals and inventory tracking based on each animal's carrying capacity.
- 🎒 **Item Transfers** — Move items and currency between the party stash, characters, and authorized pack animals.
- ✨ **Spell Management** — Tools for tracking prepared spells and characters' magical resources.
- 💬 **Customized Chat** — Themed presentation of dice rolls and actions.
- 📅 **Interactive Calendar** — Gregorian and customizable calendars for tracking time throughout your campaign.
- ⚙️ **Game Settings** — Options for measurement, encumbrance, combat, and calendar permissions.
- 🖼️ **Visual Atmosphere** — Custom system artwork and a branded logo on Foundry's pause screen.

## ⚙️ Compatibility

| **Requirement** | **Version** |

| Foundry VTT | 13 |

| Reference Material | Core Rulebook V2 |

D20Age is a **standalone game system** for Foundry VTT. No additional game system is required.

## 📦 Installation

1. From the Foundry setup screen, open **Game Systems → Install System**.
2. Paste the URL below into the **Manifest URL** field.
3. Click **Install** and wait for the download to complete.
4. Create a world and select **D20Age RPG** as its game system.
5. Launch the world to access the character sheets and tools.

```text
https://github.com/DMArkhron/D20AgeRPG-Foundry/releases/latest/download/system.json
```

### Manual Installation

1. Download the `d20age.zip` file from the GitHub Release.
2. With Foundry closed, extract the files into `Data/systems/d20age`.
3. Verify that the manifest is located at `Data/systems/d20age/system.json`.
4. Launch Foundry and create a world using the **D20Age RPG** system.

## 🎮 Getting Started

- Explore the **Compendium Packs** tab and import the resources you want to use.
- Create a character and use the character creator to guide your choices.
- Review the system settings to configure the options for your game.
- In the Actors directory, select **Create Party** to bring your adventurers together and manage their treasure.
- On the party sheet, select **Add Pack Animal** to open the pack animal compendium. Drag your chosen animal onto the sheet to add it to the party.
- Use **Transfer** to assign items or amounts of currency to their respective carriers.

For shared transfers, **a Game Master must be connected**. Access to sheets and belongings follows each user's permissions.
